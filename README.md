## StudyStack V2 改修ミッション

StudyStack V1を完成版として凍結し、V2では  
「既存システムに追加要件が発生した」という想定で保守・改修を行う。

### 必須要件

- Study投稿時に、あらかじめ定義されたタグを選択できる
- タグによるStudyの絞り込みができる
- 週間目標を設定できる

### 拡張要件

- 週間目標を約7週間分表示し、期限管理を行う
- 期限数日前の通知機能

### 改修方針

追加要件確認  
→ 既存コードの影響範囲調査  
→ 改修方針決定  
→ 小さく実装  
→ 追加テスト  
→ 既存テストによる回帰確認


## タグ機能 要件

### 基本仕様

- タグは運営側があらかじめ定義する
- 一般ユーザーによるタグの追加・編集・削除は行わない
- 1つのStudyに設定できるタグは最大2個
- タグを設定しないStudyも登録可能
- 同一Studyに同じタグを重複して設定することはできない
- StudyとTagは多対多（Many-to-Many）の関係とする

### 新規登録

- Study投稿時に定義済みタグから選択できる
- 選択したタグはチップ形式で表示する
- 最大2個まで選択可能
- 選択したタグは解除できる
- タグを選択せずにStudyを登録することも可能

### 更新

- Studyに設定済みのタグを表示する
- タグの変更・追加・解除ができる
- 更新後も0〜2個の制約を維持する
- 同じタグの重複設定は許可しない

### 一覧表示

- DashboardのStudy一覧に設定済みタグを表示する

### タグ絞り込み

- 定義済みタグを利用してStudy一覧を絞り込めるようにする

### UI方針

- タグはプルダウンから選択する
- 選択後はチップ形式で表示する
- チップからタグを解除できる
- タグ選択・解除などの操作には必要に応じてJavaScriptを使用する
- UI装飾は機能実装・動作確認後に行う


## タグ機能 影響範囲調査

### models.py

影響あり。

現在のStudyモデルは以下の情報を保持している。

- user
- content
- created_at

タグ情報を保持する仕組みが存在しないため、モデルの変更が必要。

また、1つのStudyに複数のタグを設定でき、同じタグを複数のStudyで利用するため、StudyとTagは多対多の関係となる。

TagをStudyとは別のモデルとして管理し、Studyとの関連付けを行う方針とする。


### forms.py

影響あり。

現在のStudyFormはcontentのみを入力項目として扱っている。

タグは未選択を許可するが、投稿・更新フォームからタグを選択する必要があるため、StudyFormの変更が必要。

また、以下の入力条件を扱う必要がある。

- タグ0個：許可
- タグ1個：許可
- タグ2個：許可
- タグ3個以上：不許可
- 同一タグの重複：不許可


### views.py

影響あり。

現在の新規登録では以下の流れでStudyを保存している。

- StudyFormを生成
- `form.is_valid()` で検証
- `form.save(commit=False)` でStudyを生成
- ログインユーザーを設定
- Studyを保存

タグはStudyとの多対多の関連となるため、現在のStudy本体の保存処理だけでなく、タグとの関連を保存する処理についても確認・改修が必要。

Updateについても、既存タグの取得・変更・追加・解除を扱えるよう影響範囲を確認する。


### templates

影響あり。

#### dashboard.html

現在の新規登録フォームは学習内容のみ入力可能。

以下を追加する必要がある。

- タグ選択UI
- 選択済みタグのチップ表示
- タグ解除操作
- Study一覧への設定済みタグ表示

#### update.html

以下を扱えるよう変更が必要。

- 現在設定されているタグの表示
- タグの追加
- タグの変更
- タグの解除


### tests.py

影響あり。

タグ機能追加後、新しい仕様に対するテストを追加する。

また、V1で作成済みの19件のテストをすべて実行し、既存機能が壊れていないことを回帰確認する。


## 現時点の調査結果

タグ機能の追加による主な影響範囲は以下。

- `models.py`
- `forms.py`
- `views.py`
- `dashboard.html`
- `update.html`
- `tests.py`

実装前に要件と既存処理を確認し、影響範囲を特定したうえで、小さな単位で改修を進める。
